# 논문 리딩 어시스턴트 (paper-ai-mvp)

PDF 논문을 업로드하면 AI가 구조화된 요약을 제공하고, 업로드한 논문 내용을 근거로
채팅 Q&A를 할 수 있는 웹앱입니다. 대상 사용자는 논문을 자주 읽는 대학원생
(특히 생명공학·의약학 전공)입니다.

로그인 없이 브라우저 세션(쿠키) 기준으로 96시간 동안 논문·요약·대화가 유지됩니다.

## 주요 기능

### 1. 논문 요약
- PDF만 업로드 가능, 최대 30페이지까지 처리
- 텍스트 추출이 불가능한 파일(스캔 이미지 등)은 안내 메시지와 함께 처리 중단
- 논문 원문에 없는 내용은 추측해서 채우지 않음 (환각 방지)
- 500자 이내 핵심 요약 + Key Terms & Definitions / Motivation & Problem Statement /
  Method & Key Results / Conclusion & Impact 4단계 상세 요약 제공
- 핵심 기술 용어·지표·약어는 영어 원문 그대로 유지하고 문장 구조만 한국어로 작성

### 2. 논문 Q&A 챗봇
- 한 세션에는 논문 한 편만 다루며, 새 논문을 업로드하면 이전 논문 내용은 대체됨
- 답변은 업로드된 논문 내용에 근거하며, 관련 문단·페이지 번호를 함께 표시
- 논문에 없는 일반 지식으로 답한 경우 출처를 명시
- 논문과 무관한 질문에는 답변을 거부하고 안내 메시지 표시

## 기술 스택

- **Next.js** (App Router, TypeScript) — 프론트엔드와 API 라우트를 한 프로젝트에서 처리
- **OpenAI API** — 논문 요약 및 Q&A 응답 생성
- **Supabase** — 세션(논문·요약·대화) 저장, 96시간 경과 데이터는 Vercel Cron Job으로 자동 삭제
- **Vercel** — 배포

## 로컬 실행

```bash
npm install
npm run dev
```

`http://localhost:3000`에서 확인할 수 있습니다.

다음 환경 변수를 `.env` 파일에 설정해야 합니다 (커밋되지 않음):

| 변수 | 용도 |
| --- | --- |
| `OPENAI_API_KEY` | 논문 요약·Q&A 응답 생성 |
| `SUPABASE_URL` | 세션 데이터 저장소 |
| `SUPABASE_SERVICE_ROLE_KEY` | 세션 데이터 저장소 인증 |
| `CRON_SECRET` | 96시간 만료 세션 정리 Cron Job 인증 |

## 스크립트

- `npm run dev` — 개발 서버 실행
- `npm run build` — 프로덕션 빌드
- `npm run start` — 프로덕션 서버 실행
- `npm run lint` — 린트 검사

## 비범위

여러 논문 비교, 논문 검색/추천, 회원 간 협업, 자동 번역, 로그인/회원가입, OCR 기능은
이번 범위에 포함되지 않습니다.
